# Cockpit contributor contract

Reuse the React web app, Fastify API and shared contracts. Keep the API on
loopback and preserve origin/host validation, bounded errors and telemetry-free
operation. Use isolated branches, meaningful failing regressions, minimal fixes
and the unchanged `npm run verify` gate before integration.

Hardware fixtures are synthetic evidence; they do not qualify physical operating
systems or devices. Unknown counters must not look like measured values. Keep
the two-second cache and shared in-flight collection. Graph changes must respect
reduced motion, accessible labels, cleanup and existing keyboard controls.

The Tauri proposal is documentation only. Native implementation, signing,
installers, updater publication and new permissions require their own reviewed
scope and real platform gates. Never add credentials, private operator evidence,
remote execution, paid services or telemetry to the public source.
