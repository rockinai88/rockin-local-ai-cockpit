# Roadmap

Local Ollama discovery/chat, hardware telemetry, 3D topology, Demo Mode, security gates, Windows validation.

Tauri packaging, richer hardware adapters, install/update experience.

Session opt-in persistence, MCP exploration, richer graph sources after security design review.

The roadmap is directional, not a promise. Issues and real user feedback decide priorities.
