# Contributing

Thanks for improving RockIn Local AI Cockpit.

1. Open or choose an issue before large changes.
2. Create a focused branch from `main`.
3. Follow test-first development for behavior changes.
4. Run `npm ci` and `npm run verify` before opening a pull request.
5. Keep changes local-first; do not add telemetry, cloud dependencies, secrets, or remote execution without prior design discussion.

Small, reviewable pull requests are preferred. Be respectful and follow the Code of Conduct.
