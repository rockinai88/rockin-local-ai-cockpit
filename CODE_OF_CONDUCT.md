# Code of Conduct

We use the Contributor Covenant Code of Conduct, version 2.1.

We are committed to a harassment-free, inclusive project for everyone. Be respectful, constructive, and focused on the work. Unacceptable behavior includes harassment, threats, discriminatory language, deliberate disruption, or publishing another person's private information.

Project maintainers may remove content or participation that violates these standards. For conduct reports, contact the maintainer privately through the GitHub profile rather than opening a public issue.

Full reference: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
